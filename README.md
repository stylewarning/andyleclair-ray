# Ray

A raytracer written in [Coalton](https://coalton-lang.github.io) + SBCL Common Lisp.

Based on code from [Ray Tracing in One Weekend](https://raytracing.github.io/books/RayTracingInOneWeekend.html) as well as [Fundamentals of Computer Graphics](https://github.com/t4world/Computer-Graphics/blob/master/Fundamentals-of-Computer-Graphics-Fourth-Edition.pdf) (although I have the print second version)
